# FitLog — Workout Library

FitLog is a modern and responsive workout planning and workout library web application. Users can explore different workouts, view detailed workout information, add exercises to today's plan, save workouts for later, and manage their personal workout plan.

## 🌐 Live Website

https://fit-log-nu-puce.vercel.app/

## 🛠️ Technologies Used

* Next.js (App Router)
* TypeScript
* React
* Tailwind CSS
* React Context API
* localStorage
* REST API

## ✨ Features

1. Responsive workout library with category tags, equipment information, and workout statistics
2. Detailed workout pages with key specifications and step-by-step instructions
3. Add workouts to Today's Plan with a maximum limit of 5 workouts
4. Save workouts for later
5. Toast notifications for user actions
6. My Plan dashboard with Exercises, Minutes, and Calories summaries
7. Sort workouts by Duration, Calories, and Rating
8. Mark workouts as completed
9. Remove workouts from the plan
10. Persist Today's Plan and Saved workouts using localStorage
11. Dynamic workout details pages using dynamic routing
12. Responsive interface for desktop and mobile devices

## 📦 Dependencies

Main dependencies used in this project include:

* Next.js

* TypeScript

For the complete dependency list and versions, see `package.json`.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/umme-ayman29/fit-log.git
```

### 2. Navigate to the project folder

```bash
cd fit-log
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the following URL in your browser:

```text
http://localhost:3000
```
