# FitLog — Workout Library

FitLog is a dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## Technologies Used
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React Context API
- localStorage

## Features
1. Responsive 3x4 workout library with category tags, equipment, and stats
2. Detailed workout pages with key specs and step-by-step instructions
3. Add to Today's Plan (capped at 5) or Save for later, with toast notifications
4. My Plan dashboard with live Exercises/Minutes/Calories summary and sort by Duration/Calories/Rating
5. Mark as done, remove items, and persist plan/saved data in localStorage across reloads
