# FitLog — Workout Library

FitLog is a dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## 🌐 Live Website

https://fit-log-nu-puce.vercel.app/

## 🛠️ Technologies Used

- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS
- React Context API
- localStorage
- REST API

## ✨ Features

1. Responsive 3x4 workout library with category tags, equipment, and stats
2. Detailed workout pages with key specs and step-by-step instructions
3. Add to Today's Plan (capped at 5) or Save for later, with toast notifications
4. My Plan dashboard with live Exercises/Minutes/Calories summary
5. Sort workouts by Duration, Calories, and Rating
6. Mark workouts as done and remove items from the plan
7. Persist plan and saved data in localStorage across reloads
8. Dynamic workout details pages
9. Responsive interface for desktop and mobile devices
